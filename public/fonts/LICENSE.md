# Vendored typefaces

Both files are latin-subset variable WOFF2 builds, self-hosted so the site makes no
third-party font request at runtime and the build has no network dependency on a
font CDN.

| File | Family | Licence |
|---|---|---|
| `SpaceGrotesk-latin.woff2` | Space Grotesk by Florian Karsten | SIL Open Font License 1.1 |
| `JetBrainsMono-latin.woff2` | JetBrains Mono by JetBrains | SIL Open Font License 1.1 |
